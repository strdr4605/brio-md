## 🔍 Activity & Engagement Tracking (Neon Console)

To check which directors have logged in and track their pilot engagement, run the included `pilot-audit.sql` query in the **Neon SQL Console**:

```bash
# Or run directly via terminal to synchronize all 30 sandboxes:
npm run seed:pilot
```

The audit query reports:
1. **`last_activity`**: Exact timestamp of the director's last login.
2. **`students_created_after_launch`**: Number of new students added by the school.
3. **`courses_added_after_launch`**: Number of new courses created by the school.
