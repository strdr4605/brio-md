# Linear Precision Standard (formerly stripe-craft)

> **Official Standard Notice:** The project standard is **Linear Precision × MengTo UI-Craft Synthesis**.  
> Please refer directly to [`.agents/skills/linear-craft/SKILL.md`](file:///Users/Apple/Documents/Homework/Practice/project/brio-md/.agents/skills/linear-craft/SKILL.md) and [`docs/DESIGN_SYSTEM.md`](file:///Users/Apple/Documents/Homework/Practice/project/brio-md/docs/DESIGN_SYSTEM.md).

All agents and developers must strictly follow:
1. **Primary buttons:** `#0f172a` (solid dark slate / black), text white, radius 6px.
2. **Cards:** `#ffffff` pure white, 1px border `#e2e8f0`, radius 8px, minimal shadow `0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
3. **Canvas:** `#f8fafc` clean, no ambient purple gradients or glowing orbs.
4. **Proximity over containers:** Group with whitespace, no nested border boxes.
5. **Hierarchy over labels:** No redundant metadata labels (`Phone:`, `Status:`).
6. **Zero AI-slop:** No emojis in buttons, no rainbow badge pills, no decorative filler.
