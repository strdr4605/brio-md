# Brio.md Deployment Plan

## Context

Deploy Brio.md (school management platform) to Hostinger VPS with Kamal. Three apps need subdomain routing:

- `brio.md` → Landing page
- `in.brio.md` → Staff portal
- `learn.brio.md` → Student/teacher learn portal

Also need production DB access via Drizzle Studio.

**VPS Specs**: 4GB RAM, 1 vCPU, 50GB NVMe (KVM plan at $6.49/mo)
**Server IP**: `187.127.89.56`

## Approach

- **Kamal 2** for deployment (zero-downtime, Docker-based, built-in kamal-proxy + Let's Encrypt)
- **Single config with multiple roles** for each app (landing, portal, learn)
- **Kamal proxy** handles SSL + host-based routing
- **Drizzle Studio** via SSH tunnel for security

## Files to Modify/Create

### 1. `config/deploy.yml` (rewrite)

Add `ENV PORT=3000` for Kamal compatibility

### 3. `.kamal/secrets` (create)

Secrets file for DATABASE_URL, AUTH_SECRET, POSTGRES_PASSWORD

## Reuse Existing

- Dockerfiles in `apps/*/Dockerfile`
- PostgreSQL setup from `docker-compose.yml`
- Auth config from `@brio-md/auth`

## Steps

### 1. Update Dockerfiles for Kamal

- [ ] Add `ENV PORT=3000` to all Dockerfiles
- [ ] Verify `CMD ["node", "apps/*/server.js"]`

### 2. Create/Update Kamal config (`config/deploy.yml`)

- [ ] Set server IP: `187.127.89.56`
- [ ] Configure builder with all 3 app Dockerfiles
- [ ] Add Postgres accessory
- [ ] Add Drizzle Studio accessory
- [ ] Configure env secrets

### 3. Create secrets file (`.kamal/secrets`)

- [ ] Create `.kamal/secrets` with:
  - `DATABASE_URL=postgres://brio:PASSWORD@187.127.89.56:5432/brio_md`
  - `AUTH_SECRET=your-generated-secret`
  - `POSTGRES_PASSWORD=strongpassword`

### 4. Configure DNS in Cloudflare

- [ ] Add A record: `brio.md` → `187.127.89.56` (proxy OFF)
- [ ] Add CNAME: `in.brio.md` → `brio.md` (proxy OFF)
- [ ] Add CNAME: `learn.brio.md` → `brio.md` (proxy OFF)

### 5. Server preparation (ssh root@187.127.89.56)

- [ ] Install Docker: `curl https://get.docker.com | bash`
- [ ] Add SSH key for passwordless login
- [ ] Firewall: `ufw allow 22,80,443`

### 6. Deploy

```bash
# Initial setup (creates Postgres, Drizzle containers)
kamal setup

# Deploy all apps
kamal deploy

# Deploy specific app only
kamal deploy -t landing
kamal deploy -t portal
kamal deploy -t learn
```

### 7. Access Drizzle Studio

```bash
ssh -L 4990:localhost:4990 root@187.127.89.56
# Then open: http://localhost:4990 in browser
```

## Notes

- Drizzle Studio runs as Kamal accessory, accessible only via SSH tunnel for security
- All 3 apps share one kamal-proxy instance with host-based routing
- SSL certificates auto-generated by Let's Encrypt via kamal-proxy
